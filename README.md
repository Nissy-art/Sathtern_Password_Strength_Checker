# Password Security Checker

A Python-based GUI application developed as part of the **Sathern Cybersecurity Internship**.

The Password Security Checker evaluates password strength based on common security requirements and provides users with a secure password generation feature.

##  Project Objective

The objective of this project is to develop a user-friendly password security tool that can:

* Check password strength
* Detect weak passwords
* Validate password length and complexity
* Generate strong passwords
* Provide clear security feedback to users

##  Features

*  Password strength analysis
*  Weak password detection
*  Length and complexity validation
*  Strong password generation
*  Show/Hide password
*  Copy password to clipboard
*  Clear password
*  User-friendly graphical interface

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter** — GUI development
* **Regular Expressions (re)** — password validation
* **Secrets module** — secure random password generation
* **String module** — character generation

##  Password Requirements

The application checks whether a password contains:

* Minimum 8 characters
* At least one uppercase letter
* At least one lowercase letter
* At least one number
* At least one special character

The application categorizes passwords as:

* Very Weak
* Weak
* Moderate
* Strong
* Very Strong

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Sathtern_Password_Strength_Checker.git
```

### 2. Open the project folder

```bash
cd Sathtern_Password_Strength_Checker
```

### 3. Run the application

```bash
python3 password_checker.py
```

##  Application

The application provides an interactive GUI where users can enter a password, check its strength, view individual security requirements, and generate a strong password.
